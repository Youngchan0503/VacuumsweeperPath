# 🚛 DaeguDust Studio - 대구 분진흡입차량 운행 경로 개선 & 실시간 대기정보 관제

대구광역시 주요 간선도로(달구벌대로, 신천대로, 동대구로 등)의 **도로 재비산먼지 저감을 위한 분진흡입차량 운행 경로 최적화 분석**과 **대구광역시 실시간 대기정보 시스템(air.daegu.go.kr) 실시간 크롤링 연동 관제 플랫폼**입니다.

---

## 🌟 주요 기능 및 특징

1. **대구광역시 행정구역 인터랙티브 SVG 벡터 지도 (`daegu-map.svg`)**
   - 8개 구·군(중구, 동구, 서구, 남구, 북구, 수성구, 달서구, 달성군) 정밀 벡터 폴리곤
   - 마우스 호버(스카이블루) 및 선택(에메랄드) 애니메이션 인터랙션
   - 상단 `SVG 다운로드` 버튼으로 원본 SVG 직접 내려받기 지원

2. **대구광역시 실시간 대기정보(air.daegu.go.kr) 크롤링 연동**
   - **실시간 대기 모니터링**: 22개 대기측정소(수창동, 만촌동, 이현동, 노원동 등)의 시간대별 PM10, PM2.5, O3, CAI 지수 실시간 크롤링
   - **공식 대기정보 테이블 뷰어 모달**: 대구시 보건환경연구원 공식 표 규격(일시, 통합지수, 미세먼지, 초미세먼지, 상태 아이콘) 100% 동일 구현
   - **구·군 클릭 시 자동 연동**: SVG 지도에서 자치구를 클릭하면 해당 지역의 대표 대기측정소로 자동 동기화

3. **분진흡입차량 경로 전·후(Before vs After) 개선도 분석**
   - 8대 전담 분진흡입차량(DS-01~08) 운행 효율 분석 (거리 -31.4% 단축, PM10 41.8% 저감)
   - 최적화 전/후 주행거리, 소요시간, 분진 포집량 비교
